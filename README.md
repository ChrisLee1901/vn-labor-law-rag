# Trợ lý Pháp luật Lao động

Trợ lý Pháp luật Lao động là hệ thống RAG pháp luật lao động tiếng Việt end-to-end: thu thập và cấu trúc văn bản, truy hồi lai, sinh câu trả lời có trích dẫn Điều/Khoản. LLM tự host trên Kaggle; giao diện Next.js và API FastAPI chạy trên Vercel.
